# 단계별 시연 출력 개선

2026-10-23 학생 시연의 진행감을 높이기 위해 계산 결과를 바꾸지 않고 Jupyter 출력만 개선했습니다.

- 01 비밀번호: 각 위치의 36개 SAD 막대를 갱신하고 선택 문자를 빨간색으로 표시합니다. 오른쪽에는 `h → h0 → h0p → h0px → h0px3` 접두사가 0.8초 간격으로 자랍니다. 마지막 셀은 다섯 위치의 heatmap을 유지합니다.
- 02 TVLA: 그룹당 10, 25, 50, 75, 100개 순서로 최대 `|t|` 그래프를 갱신하고 기준선을 넘으면 `LEAKAGE DETECTED`를 표시합니다.
- 03 AES: CPA로 계산한 실제 키 바이트를 0.18초 간격으로 16칸에 채웁니다. 마지막 출력은 expected/recovered 키와 16/16 일치를 남기고, 다음 셀에서 바이트별 상관 피크를 표시합니다.

애니메이션은 `IPython.display.clear_output(wait=True)`와 실제 계산 결과만 사용합니다. 고정 반환값이나 연출용 가짜 키는 없습니다. 생성 스크립트와 네 노트북의 모든 코드 셀은 Python 문법 검사를 통과했으며, 노트북은 시연 때 새 파형을 수집하도록 미실행 상태로 저장했습니다.
